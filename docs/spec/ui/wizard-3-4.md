## 1. ③ 目标服务端页

### 1.1 绘制模型（本页最关键的条款）

**这是本页的主要缺陷，也是本节的第一个条款**——不是"加动效"，是**修掉伪动效**。

#### 现状根因（实测）

`src/wizard/mod.rs` 里 ③ 页的页面标题走**裸 `eprintln!`**（第 114 行 `\n③ {}`，另有 157 / 163 行），而三个 prompt 走 `inquire`。两者**不在同一网格、不共享绘制者**：

- 标题字节**只写一次、从不重绘、也从不擦除**；
- `inquire` 的 prompt 在同一区域**反复用 `EL` 擦写**自己的行。

于是 prompt 的擦写把静态标题块「扫」过一遍又一遍，视觉上就是同一块 UI 被反复叠印。

#### 与 #23 一致的断言锚点

[motion.md](motion.md) §3.6 已把断言定为两层。**本文直接引用，不另立**：

| ID | 层 | 断言 | 期望 |
|---|---|---|---|
| **A1** | 逻辑 | ③ 页每个逻辑行只被**逻辑绘制一次** —— `src/wizard/**` 内不得出现 `print!`/`println!`/`eprint!`/`eprintln!`（渲染入口之外） | **0 处**（当前 **11 处**，全在 `src/wizard/mod.rs`，行号 58/91/98/99/100/101/102/114/157/163/190） |
| **A3** | 物理 | `data.count(b'\x1b[2J')`（ED(2)，整屏清） | **== 0** |

> **不要引用任何具体重绘次数**。早期版本里的「7」已废弃（字节计数强依赖交互步数）；#20 的逐格统计为：最短路径 **3** 次、快速确认 **3** 次、键入过滤词可达 **15** 次。物理重绘由 `Buffer::diff()` 决定，**不是断言对象**。

#### 绘制模型不变量（I1–I4，引自 motion.md §3.2）

| # | 不变量 |
|---|---|
| I1 | **单写者**：页面标题、字段、预览面板**全部**由同一个绘制者写入 |
| I2 | **单网格**：主表单与右侧预览面板**共享同一张 `Buffer`** |
| I3 | **每帧一次 `Terminal::draw()`**，由 `Buffer::diff()` 决定实际写哪些格子 |
| I4 | 每帧包在 `BeginSynchronizedUpdate`（DEC 2026）内**原子提交** |

### 1.2 依赖顺序必须在版式上看得出来

spec §4.2 冻结顺序：**先选 MC 版本** → **再选平台**（按该版本过滤，代理端恒在）→ **最后元数据格式**（二选一）。

**现状缺陷**：三个 `Select`/`MultiSelect` 在视觉上**平级并列**，看不出「平台列表取决于已选版本」。

**决定**：用**缩进层级 + 依赖标记**表达顺序。

| # | 规则 |
|---|---|
| D1 | 三组各自占一个**字段块**，块间空 1 行；块顺序 = 依赖顺序，**不可交换** |
| D2 | 第 2 组（平台）与第 3 组（元数据）**各缩进 `indent.unit` × 1**，表示「它们依赖于上一组的结果」 |
| D3 | 每组标签行右侧（`col.form.right` 处，`faint`）写**该组的约束说明**：<br>MC 版本 → `只列受支持的版本`<br>平台 → `按 {mc} 过滤 · 代理端恒在`<br>元数据 → `与 plugin.yml 互斥` |
| D4 | 当前活动组的**标签用 `accent`**，非活动组用 `dim`；已确认的组标记 `nav.done`（`✓`） |
| D5 | 平台组在「MC 版本」尚未确认前**不渲染**（不可交互）——顺序是硬性的，不是提示 |

### 1.3 平台列表：Java 要求与 `experimental` 标记

来源（`src/wizard/mod.rs:127-155` + `form::platform_options`）：平台列表 = `matrix.available_platforms(&form.mc)`，**代理端（velocity / bungeecord）恒在**。

**实测 Java 要求**：`paper` / `bukkit` = 21，`velocity` = 25，`bungeecord` = 8，`folia` / `sponge` = 21，`minestom` = 25。

| # | 规则 |
|---|---|
| P1 | 平台列表最多 **7 项**，每项一行：**`标记列` + `勾选框` + `平台名` + `Java 要求`** |
| P2 | **平台名列定宽** `label.w`（= 11），左对齐；**Java 要求列右对齐**至 `col.form.right` |
| P3 | Java 要求用 `faint`，格式 `Java {n}`；**它是只读事实，不是选项**——不得表现为可交互 |
| P4 | `experimental` 标记（folia / sponge / minestom）放在**平台名之后、Java 列之前**，用 `faint` 的 `实验性` 二字 |
| P5 | **不喧宾夺主**：`experimental` 不得用 `warn`/`err` 色，不得加图标；它与平台名之间只空 1 格 |
| P6 | **能力列不作视觉元素**：GUI / bStats / PlaceholderAPI 依赖 Bukkit 系 API，而 `bungeecord`（代理端）与 `sponge`/`minestom` **不生成**这些模块（清单 `templates/vinoa-template.toml` 已按此修正为 `any_of(is_paper, is_folia, is_bukkit)`）。因此**不要在平台行上标注「支持 GUI」之类的能力列**——会与实现打架 |

### 1.4 「勾 paper 自动带上 bukkit」如何被用户看见

现状（`src/wizard/mod.rs:157-165`）：选完平台后**补打一行** `· paper 会自动带上 bukkit 兼容模块`。

**这条信息出现在错误的位置**——它是**选择前**该知道的规则，不是**选择后**的报告；而且它是裸 `eprintln!`，正是 A1 要消灭的 11 处之一。

**决定**：

| # | 规则 |
|---|---|
| B1 | 把该提示**前移**到平台组标签行的约束位（D3），与 `按 {mc} 过滤 · 代理端恒在` 并列：`勾 paper 自动带上 bukkit` |
| B2 | 当用户**勾了 paper 后**，`bukkit` 那一行**自动变为勾选态**，并在该行 Java 列左侧以 `faint` 追加 `· 由 paper 带入` —— 让自动行为**在受影响的那一行上**可见，而不是在页脚说一遍 |
| B3 | 用户**手动取消** `bukkit` 时：若 `paper` 仍勾选，则**拒绝**并给出行内错误（贴住该行）：`勾 paper 时 bukkit 必带` |
| B4 | 预览面板同步：`platforms/` 下出现 `bukkit  N files` —— 自动行为在产物树上也可验证 |

## 2. ④ 附加页

### 2.1 两类控件的视觉区分（本页核心）

现状（`src/wizard/mod.rs:199-264`）：五个可选模块走 `MultiSelect`（多选），四个默认开的确认走 `Confirm`（`Y/n`）。**两者在视觉上混在一起**，但语义完全不同。

| 控件 | 语义 | 默认 | 控件形态 |
|---|---|---|---|
| **多选**（`WIZARD_FEATURES` 五项） | 加不加这个模块 | **全不勾** | `[ ]` / `[x]` 勾选框 |
| **三态确认**（示例/权限/质量/git） | 要不要关掉这个默认项 | **默认开** | `(Y/n)` 后缀 |

**决定**：用**三组不同的视觉信号**区分，且**每一组在无色档下仍可辨**。

| # | 规则 |
|---|---|
| X1 | **分块**：两类控件**分属两个字段块**，各有一个 `dim` 标题行（可选模块 / 默认开启项），块间空 1 行。**绝不混排** |
| X2 | **标记列不同**：多选行用 `check.off` / `check.on`（`[ ]` / `[x]`）在 `col.cursor` + 2 列；确认行**无勾选框**，改为**行尾** `(Y/n)` 后缀 |
| X3 | **默认值语义显式化**：确认行的 `(Y/n)` 中，**大写字母表示默认值** —— `(Y/n)` = 默认开、`(y/N)` = 默认关。这与 `Y/n` 的既有语义一致，且**无色档完全可辨**（不依赖颜色） |
| X4 | **缩进不同**：可选模块块缩进 `indent.unit` × 1；确认块缩进 `indent.unit` × 1，但**标题行不缩进**，形成"两个子区"的层级 |
| X5 | 确认行的**当前值**用 `fg`，默认提示 `(Y/n)` 用 `faint` |

### 2.2 `bStats` 的条件追问（页内嵌套输入）

现状（`src/wizard/mod.rs:207-225`）：勾了 `bStats` 后，用**一个新的 `Text::new(...)` prompt** 追问数字 plugin id，且带 `loop` 重试与 `numeric_validator`。

**这是页内嵌套的输入**，在全屏接管下必须表现为**行内展开**，而不是"再起一个 prompt"（那会破坏 I1 单写者）。

| # | 规则 |
|---|---|
| N1 | 用户在可选模块块勾选 `bStats` 后，**在该行下方同帧展开一行输入**：`bStats 数字 plugin id  [____]` |
| N2 | 展开行缩进 `indent.unit` × 2（比模块行再深一级），表示它是**该模块的子字段** |
| N3 | 输入框用 `caret`（`▏`）标记位置；`fg` 色 |
| N4 | 展开行右侧（`col.form.right`，`faint`）写来源说明：`在 bstats.org 新建插件后取得` |
| N5 | **校验失败时**：错误**贴住该展开行**（在其下方再展开一行 `err` 提示），**不**跳到页脚。文案：`须为数字；缺失会硬报错` |
| N6 | **取消勾选 `bStats` 时，展开行同帧收起**，不留空行（I3 的 diff 会自然处理） |
| N7 | 缺失 id 是**硬报错**（spec §11.1 / `is_valid_bstats_id`），绝不生成假 id——追问不可跳过 |

### 2.3 生成物语言

现状（`src/wizard/mod.rs:266-277`）：`Select` 三选一（`中文` / `English` / `双语`）。

| # | 规则 |
|---|---|

| L2 | 三个选项**排在同一行**（横排），用 `sep`（`·`）分隔，光标用 `❯` |

## 3. 降级形态

> **触发条件与优先级不在本文定义**：一律引用 [degradation.md](degradation.md) §1.8 的优先级链与 §2.1 的能力层。

### 3.1 无色档（任一宽度）

| 元素 | 无色替代 | 依据 |
|---|---|---|
| `accent`（当前项 `❯` / 活动组标签） | 保留 `❯`、`▸` 字形；标记列是**独占列**，整屏只有当前项在该列有字形 | tokens.md §3.5 |
| `ok`（`✓` 已完成） | 保留 `✓` | tokens.md §3.5 |
| `err`（`✗` 未检测到 / 校验错误） | 保留 `✗` | tokens.md §3.5 |
| `warn` | 前缀 `!` | tokens.md §3.5 |
| `dim`（标签） | **缩进 +1 级** | tokens.md §3.5 |
| `faint`（约束说明 / Java 列 / 来源说明） | **缩进 +1 级 + `·` 前缀** | tokens.md §3.5 |
| `border`（框线 / 分栏竖线） | 保留框线字形 | tokens.md §3.5 |

**本页特有的无色风险点**：③ 页的 Java 要求列与 `experimental` 标记**都靠 `faint` 与列位**区分。无色档下二者同为默认前景，**必须靠列位与 `·` 前缀**保持可辨（P5 已要求 `experimental` 在 Java 列之前，天然形成列序）。

### 3.2 窄终端

| 宽度 | 形态 |
|---|---|
| ≥ 100 | 完整：框 + 导航条 + 预览面板 |
| 80–99 | **丢预览面板**，表单占满（[direction.md](direction.md) §4） |
| < 80 | **丢整屏边框**，退化为连续流；导航条压成一行页位 |
| < 60 | 单栏；③ 页平台行的 Java 列**换行到下一行**（而非截断——它是事实，不可省） |

**③ 页在 < 80 列时的平台行**：

```
平台    按 1.21.11 过滤 · 代理端恒在
        勾 paper 自动带上 bukkit
❯ [x] paper       Java 21
  [x] bukkit      Java 21  · 由 paper 带入
  [ ] velocity    Java 25
```

### 3.3 ASCII 字形档

`tree.*` / `check.*` / `sep` / 框线的 ASCII 回退见 [tokens.md](tokens.md) §4。**勾选框 `[x]` / `[ ]` 已是 ASCII，无需回退**。

|---|---|---|---|
